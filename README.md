# CE-ScreenCopy
A simple screen-mirroring tool for MacOS to Ti-84 Plus CE!

Build is currently only for MacOS.

1. Transfer the 8xp file to the calculator (Ti-84 Plus CE ONLY) via Ti-Connect.
2. download the files as a .Zip
3. extract them onto your DESKTOP!
4. copy and paste the command to build the app (in "OPEN ME!!!")
5. Open the app and allow permissions
6. bang! it should run!
